Add a computer: five ways, none with tabs

Replaces the New connection dialog (tabs Manual, Find on network, Pairing code). Each is shown on the v4 design 6 shell, full (two PCs found on the network, an address typed) on the left and empty (first run, nothing found yet) on the right. All of them keep the rule that nothing is sent before you compare the key.

1 · One field — an address or a pairing code, and the PCs on this network belowNo tabs and no form: one field that takes either an address (host:port) or a pairing code and says which it understood. Below it, the PCs found on this network are one click each. The name comes from the PC itself.
2 · Steps — find the PC, check its key, sign in, with the way ahead shownAdding a computer is three steps, and the dialog says so: find it, check its key, sign in. The steps sit on the left so you always know how far you are; step one offers the network list and a typed address side by side, never as tabs.
3 · Network first — the PCs around you as cards, typing only when it is not thereMost people add a PC sitting on the same network, so the dialog opens on what it found: one card per PC with its system and key. Typing an address is the fallback, one line at the foot, for Tailscale and the internet.
4 · Code first — type the code the PC shows, and that is the whole jobBuilt around the pairing code that rfe setup prints on the PC: eight boxes, typed once, and the PC is found, checked and let in. An address or the network list are quiet alternatives below, for PCs you sign in to with an account.
5 · Live check — a side sheet that tests the address as you type and shows the key at onceNot a modal: a sheet on the right, in the same place and style as the inspector. As you type, it checks the address live: reachable, which agent, and the key you will be asked to trust, so comparing it with the PC happens here, not in a second dialog.
