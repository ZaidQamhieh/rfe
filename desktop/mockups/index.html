RFE Desktop: 20 design directions

Each mockup is a static HTML file at the app's default 1280×800 window size and shows the same data, so you can compare the designs directly. Each one changes how the app is organised: layout, navigation, visual style and interaction model. None is a re-skin of another. Every design keeps every current feature. Each card says where a feature lives when it is not on the main screen.

Open a card, then use [ and ] (or the links in the top strip) to page through the designs. A few are interactive: in 01, Ctrl K opens the palette; in every design, rows show hover states.
